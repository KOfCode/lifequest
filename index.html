📜 规则

• 每完成一项任务得经验（XP）：三餐各 +15，饮水满 2000ml +20，23:00 前上床 +20，完成训练副本 +50，其它习惯 10–50 不等。

• 每天计入等级的经验上限 160 XP（超出部分只计入属性），保证升级稳定不注水。

• 升级所需经验逐级增加：第 n 级升到 n+1 需要 300 + 100×(n−1) XP。认真坚持 2–3 周约到 Lv5。

• 人物形态：Lv1 普通身材 → Lv3 运动觉醒 → Lv5 薄肌学徒 → Lv8 腹肌显影 → Lv12 薄肌战士 → Lv16 银红战甲。

• 五大属性：体魄（健身）、智识（学习）、乐感（音乐）、财商（投资）、创造（副业），各自独立升级。

• 连续打卡：当天完成至少 3 项任务算一天，断一天归零。

• 周/月/季任务按周期计数，到期自动重置（周 = 周一至周日）。
